# Security Policy

## Supported version

Security fixes are applied to the current default branch. Older tags are not maintained separately.

## Reporting a vulnerability

Please use the repository’s private security-advisory feature to report a suspected vulnerability. Include the affected component, reproducible steps, impact, and any safe supporting material. Do not open a public issue for an unpatched vulnerability.

## Project boundary

SOCWerk is a local educational lab that processes synthetic scenario content. It does not provide offensive operations or real containment. Reports about missing offensive features, external target access, or real-world enforcement integrations are outside the supported product boundary.

The project does accept reports involving scenario path traversal, script injection, unsafe rendering, query or database injection, unexpected network access, solution disclosure before submission, or exposure of sensitive local data.
